# 교구 · 구역 심방 관리

구역 식구 한 사람 한 사람을 기억하고, 기도하고, 연락하기 위한 한 장짜리 페이지입니다.
`index.html` 파일 하나만 브라우저로 열면 바로 쓸 수 있습니다. (설치·서버 불필요)

## 기능

- **성도 등록** — 이름, 직분, 구역, 연락처, 기도 제목 메모
- **심방 기록** — 심방 날짜, 구분(가정심방·병원심방·전화심방 등), 심방 내용
- **구역별 명단** — 구역마다 이름이 쭉 나열되고, 최근 심방일과 경과일이 한눈에 보임
- **심방이 오래된 분이 위로** — 각 구역 안에서 마지막 심방이 오래된 순으로 정렬
- **상단 요약** — 전체 인원 / 60일 이상 미심방 / 90일 이상·기록 없음
- **검색 · 구역 필터**
- **내보내기 · 가져오기** — JSON 파일로 백업하고 다른 기기에서 이어서 사용

## 경과일 표시

| 배지 | 의미 |
| --- | --- |
| 초록 | 최근 60일 이내 심방 |
| 노랑 | 60일 이상 미심방 |
| 빨강 | 90일 이상 미심방 |
| 보라 | 심방 기록 없음 |

## 사용 방법

1. `index.html` 을 브라우저에서 엽니다.
2. **＋ 성도 추가** 로 구역 식구를 등록합니다.
3. 명단에서 이름을 누르면 상세 창이 열리고, 그 안에서 심방 날짜와 내용을 기록합니다.
4. 가끔 **내보내기** 로 백업 파일을 받아 두시면 안전합니다.

## 자료 보관 위치

입력한 내용은 서버로 전송되지 않고 사용하는 브라우저의 localStorage 에만 저장됩니다.
따라서 다른 기기·다른 브라우저에서는 보이지 않으며, 브라우저 데이터를 지우면 함께 지워집니다.
여러 기기에서 쓰시려면 **내보내기 / 가져오기** 를 사용하세요.
성도의 개인 정보가 담기므로 공용 컴퓨터에서는 사용 후 정리해 주시기 바랍니다.
